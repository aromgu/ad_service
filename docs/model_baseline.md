# 모델 개발 베이스라인 실행서

## 완료 기준

- 상품 7종 모두 광고 문구와 이미지 3종을 생성한다.
- 문구 모델 3개, 이미지 모델 2개를 동일 입력으로 비교한다.
- JSON 파싱 성공률 100%, 오류와 비용은 `experiment.jsonl`과 `budget.json`에 남긴다.
- 제품 보존 점수 4/5 미만과 확인되지 않은 상품 주장은 탈락시킨다.

## 실행 순서

1. `prepare-data`로 `eval_v1`을 만든다.
2. mock 공급자로 1건을 생성해 경로·폰트·합성을 확인한다.
3. GPT-5.4 Mini/Nano와 Qwen3-8B를 각각 실행한다. 이미지 공급자는 mock으로 고정한다.
4. GPT-Image-2와 FLUX.2 Klein 4B를 각각 실행한다. 문구 공급자는 mock으로 고정한다.
5. 대표 상품 `snack_001`, `snack_004`, `snack_007`을 seed 11과 22로 추가 실행한다.
6. 평가표를 만들고 박창준·황인홍이 독립적으로 점수를 입력한다.
7. 모델별 평균을 집계한다. 3점 이내 동점이면 비용, 지연 순으로 선택한다.

## 비용 계획

- GPT-Image-2 medium 21장은 공식 단가 기준 약 $1 이내이며 텍스트 입력 비용은 별도다.
- 코드의 사전 추정치는 지원 규격별 공개 단가를 사용한다.
- 실행 전후 팀 채널의 `!usage`로 실제 팀 사용량도 확인한다.
- 프로젝트 코드의 누적 상한은 $10, 팀 전체 상한은 $30이다.

## 결과 전달

구아롬에게는 `GenerationRequest`, `GenerationResult`, `/v1/generate`와 환경 변수 목록을 전달한다.
이태훈에게는 각 `result.json`과 PNG 3종, `text_safe_area` 좌표를 전달한다. 한글 최종 렌더링은
서비스의 HTML/Canvas로 교체해도 결과 스키마는 유지한다.

## 직접 학습 판단

이번 베이스라인에서는 파인튜닝하지 않는다. 직접 학습이 필수이거나 반복되는 한국어 카피 실패가
프롬프트로 해결되지 않고 검수 문구 500쌍 이상이 확보된 경우에만 Qwen3-8B QLoRA를 별도 단계로
진행한다. 상품 7종 이미지는 이미지 LoRA 학습에 사용하지 않는다.
